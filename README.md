## 🚀 What is claude-usage-mac?

claude-usage-mac is a simple macOS application that shows your Claude Code token usage and cost right in your menu bar. It also comes with a desktop widget so you can see your statistics at a glance without opening any other programs.

If you use Claude Code for programming or other tasks, this app helps you keep track of how many tokens you're using and how much it costs. This is useful for staying within budgets or just understanding your usage patterns.

The application sits quietly in your menu bar (the top bar on your Mac screen) and updates automatically. You don't need to remember to check anything. The widget can be added to your Notification Center or desktop (depending on your macOS version).

## ✨ Key Features

- **Menu bar display** – See your current token usage and cost directly in the macOS menu bar
- **Desktop widget** – Add a widget to your Notification Center for quick reference
- **Automatic updates** – The app refreshes your usage data without you doing anything
- **Cost tracking** – Know exactly how much each session costs in real time
- **Token counting** – Track both input and output tokens separately
- **History view** – See your usage over time (daily, weekly, monthly)
- **Minimal resource usage** – The app runs in the background and uses very little CPU or memory
- **macOS native** – Built with Swift and SwiftUI for smooth performance on any Mac

claude-usage-mac works on any Mac running macOS 13 (Ventura) or later. If you have an Apple Silicon Mac (M1, M2, M3) or an Intel-based Mac, the app will work fine. It needs about 50 MB of disk space and a few MB of RAM.

## 🛠️ How to use claude-usage-mac

Using the app is straightforward:

1. After launching, click the menu bar icon (it looks like a small graph or text symbol)
2. A dropdown menu shows your current token usage and estimated cost
3. Click "Open Widget" to add the widget to your Notification Center
4. To configure settings, click "Preferences" in the menu
5. In preferences, you can set your Claude API key (if needed) and choose which data to display

The widget shows the same information in a larger format that you can glance at without clicking anything.

## 📊 What the widget shows

The desktop widget displays:

- Current session token count
- Total cost for the current session
- Tokens used today
- Cost for today
- A small graph of usage over the last few hours (on supported macOS versions)

You can resize the widget and choose between different display styles (compact, detailed, or graph-focused).

## 🔒 Privacy and data

claude-usage-mac does not send your data anywhere. All usage information stays on your Mac. The app only reads token usage data from Claude Code if you have it installed. No personal information is collected, stored, or transmitted.

If you choose to enter an API key in preferences, that key is stored securely in your Mac's Keychain.

## 🐛 Troubleshooting

**The app doesn't show any data**
Make sure Claude Code is installed and configured on your Mac. The app needs Claude Code to be running or have past usage logs.

**The menu bar icon is missing**
Check if the app is running in your Dock or Activity Monitor. If it's not, relaunch it.

**Widget shows zeros**
It may take a few seconds for data to appear after first launch. If it stays zero, check your Claude Code setup.

**Can't find the download link**
Visit the GitHub page and look for the "Releases" section on the right side of the page. Click the "Latest" release link.
